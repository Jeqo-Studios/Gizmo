## Overview
Gizmo adds polished utility flows to Minecraft servers with configurable welcome screens, fullscreen fade effects, and resource-pack-backed visuals. It is designed to help server owners create a more guided and cinematic player experience while keeping configuration practical for day-to-day use.

## Highlights
- Custom welcome and information screens powered by resource pack assets
- Fullscreen fade effects with configurable timing and progression behavior
- Support for first-join-only screens and once-per-restart display flows
- Configurable screen items, sounds, messages, commands, and player handling
- PlaceholderAPI soft dependency support for richer server integrations

## Installation
1. Build or download the `Gizmo` plugin JAR.
2. Place it in your server's `plugins` folder.
3. Start or restart your server.
4. Review the generated files in `plugins/Gizmo`.
5. Configure your resource pack, `config.yml`, `messages.yml`, and `screens.yml` to match your server's experience.

Gizmo is currently configured against API version `26.2` in this repository.

## Development
### Requirements
- Java `25`
- Maven

### Build
```bash
mvn package
```

The packaged plugin JAR will be created in `target/`.

## Documentation
The best place to start is the configuration generated by the plugin itself, especially `config.yml`, `messages.yml`, and `screens.yml`. Those files define the welcome screen flow, fade behavior, commands, sounds, and item-based screen layout used by Gizmo.
